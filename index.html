首次使用：Google Cloud 設定教學
  1. 前往 Google Cloud Console，建立新專案。
  2. 在左側選單選擇「API 和服務 > 程式庫」，搜尋並啟用 Google Drive API。
  3. 前往「API 和服務 > 憑證」，點選「建立憑證 > OAuth 用戶端 ID」。
  4. 應用程式類型選 網頁應用程式。
  5. 在「已授權的 JavaScript 來源」加入：
    http://localhost（本機測試）
    https://你的帳號.github.io（GitHub Pages 部署後）
  6. 建立後複製 用戶端 ID，貼入下方欄位。
Client ID 只存在你的瀏覽器 localStorage，不會傳送至任何伺服器。
GitHub Pages 部署：將整個 reimburse-web/ 資料夾推至 repo，在 Settings → Pages 啟用即可。
